💳 Credit Card Default Prediction
This project is currently in progress and focuses on predicting the likelihood of credit card default using a dataset of over 30,000 clients from Taiwan. The data includes demographic details, credit limits, past payment records, and monthly billing statements from April to September 2005. The goal is to explore patterns in repayment behavior and identify key factors that influence default risk. The project involves data cleaning, exploratory analysis, and building machine learning models such as Logistic Regression, Random Forest, and XGBoost to predict defaults. Tools used include Python, Pandas, Scikit-learn, and Matplotlib. Insights from this analysis can help financial institutions better assess credit risk and tailor strategies accordingly.
